# Easy PDF Merge

เครื่องมือย่อยสำหรับรวม PDF จำนวนมากแบบปลอดภัยและใช้ง่าย โดยไม่ต้องแก้ path ใน Python ทุกครั้ง

## จุดที่เพิ่มเข้ามา

- เรียงไฟล์แบบ Natural Sort (`1, 2, 10` แทน `1, 10, 2`)
- รองรับชื่อไฟล์ `page_001.pdf` ถึง `page_176.pdf`
- รองรับชื่อที่มีเลขอื่นอยู่ก่อนหน้า เช่น `รวมเลขแก้26-08_page_001.pdf`
- ตรวจเลขท้ายชื่อไฟล์ว่าต่อเนื่องหรือมีเลขหาย/เลขซ้ำ
- โหมด Strict สำหรับงาน 176 แผ่น: ถ้าจำนวนหรือลำดับไม่ถูกต้องจะไม่ยอมรวม
- รองรับ path ที่มีช่องว่างและภาษาไทย
- ไม่เอาไฟล์ผลลัพธ์ `รวมแผ่น.pdf` กลับมารวมซ้ำ
- เขียนไฟล์ชั่วคราวก่อน แล้วค่อยแทนไฟล์ผลลัพธ์เมื่อรวมสำเร็จ

## วิธีง่ายที่สุดสำหรับงาน 176 แผ่น

ใช้ `MERGE_176_PDF.bat`

1. ลากโฟลเดอร์ที่มี PDF ทั้ง 176 ไฟล์ไปวางบน BAT หรือ Double-click BAT แล้ว paste path
2. โปรแกรมตรวจว่ามี 176 ไฟล์ และตรวจเลขท้ายชื่อไฟล์
3. ถ้าถูกต้อง จะสร้าง `รวมแผ่น.pdf` ในโฟลเดอร์เดียวกัน

ตัวอย่าง path:

```text
J:\My Drive\1.4.3 ส่วนหลัก ทวีปแอฟริกา\Africa_1_4_3\กพด\แยก 1-176\รวม
```

## ถ้าจำนวนไฟล์ไม่ใช่ 176

ใช้ `MERGE_PDF_FOLDER.bat` ซึ่งไม่บังคับจำนวนไฟล์

## ใช้ Python โดยตรง

```powershell
python merge_pdf.py "J:\path\to\folder" --expected 176 --strict
```

หรือ:

```powershell
py -3 merge_pdf.py "J:\path\to\folder" --expected 176 --strict
```

## Dependency

ใช้ PyMuPDF ซึ่งเป็น dependency เดียวกับ PDF Drawing Tool อยู่แล้ว

```powershell
python -m pip install PyMuPDF
```

BAT จะพยายามติดตั้งให้อัตโนมัติถ้ายังไม่มี
