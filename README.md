# ABD_zoo

As-built drawing tools and utilities for the ABD Zoo project.

## PDF Drawing Tool

Windows desktop utility for engineering drawing PDFs:

- Auto-detect the `แผ่นที่` title-block cell
- Sequential sheet numbering
- Cordia New / installed Windows fonts
- AutoCAD SHX annotation cleanup
- PDF preview/editor tools
- Merge / Split PDF
- Build to Windows `.exe`
- Optional Windows installer with Desktop / Start Menu shortcuts
